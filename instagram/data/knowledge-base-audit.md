   - n8n: 2-3 hours to learn, 30min per workflow
   - ManyChat: 20-30 min for basic flow
   - Claude Projects: 5 min setup

3. **Integration specifics** — Which tools work together seamlessly?
   - Claude + n8n via API ✅

4. **Real workflow examples** — Abstract "use cases" vs concrete "here's my exact workflow"
   - Good: "Comment GUIDE → auto-DM" 
   - Missing: "Wake up → Claude drafts 3 captions → Canva templates → Buffer schedules → done in 20min"

5. **Cost scaling warnings** — What happens at scale?
   - Zapier: Costs explode at volume
   - Make.com: Operations cap hit quickly
   - n8n self-hosted: Scales to infinity
   - This info is partially there but not emphasized

6. **Failure modes** — What breaks?
   - Instagram API limits
   - ManyChat flow complexity limits
   - Claude rate limits on free tier
   - Missing entirely

### Verdict:
Knowledge base is broad but could use more depth in setup times, real workflows, and failure modes.
