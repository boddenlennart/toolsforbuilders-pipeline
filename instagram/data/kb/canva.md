## Solopreneur workflows (concrete step-by-step)

### Workflow: Daily Social Graphics
1. Open Canva, select platform template (IG, LinkedIn, etc.)
2. Choose template that fits your brand
3. Customize colors, fonts, images
4. Use Magic Write for caption suggestions
5. Resize for multiple platforms with one click
Result: Consistent branded content in minutes

### Workflow: Content Batch Creation
1. Set up Brand Kit (Pro) with colors, fonts, logos
2. Create template for each content type
3. Batch edit: swap text/images for each post
4. Export all at once
5. Schedule for the week
Result: Week of content in one session

### Workflow: AI-Assisted Design
1. Start with rough idea or prompt
2. Use Magic Design to generate options
3. Magic Expand to fix awkward crops
4. Magic Eraser to remove unwanted objects
5. Background Remover for product shots
Result: Professional designs without design skills

### Workflow: Presentation Creation
1. Select presentation template
2. Use Magic Write to draft slide content
3. AI generates layout suggestions
4. Add brand elements automatically
5. Present directly or export to PPT
Result: Polished presentations fast
