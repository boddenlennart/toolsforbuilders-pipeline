## Solopreneur workflows (concrete step-by-step)

### Workflow: Image + Caption in One Session
1. Open ChatGPT with DALL-E access
2. "Generate an image of [your content concept]"
3. Iterate on the image until satisfied
4. "Now write an Instagram caption for this image in [your brand voice]"
5. Image + caption done in one conversation
Result: Cohesive visual + copy without switching tools

### Workflow: Custom GPT for Repetitive Tasks
1. Create a Custom GPT with your instructions
2. Include: brand voice, common formats, things to avoid
3. Give it example outputs you've approved
4. Name it something memorable ("My Caption Writer")
5. Use for all similar tasks going forward
Result: Consistent outputs without re-explaining every time

### Workflow: Voice-First Content Drafting
1. Use ChatGPT mobile app with voice mode
2. Speak your content ideas stream-of-consciousness
3. Ask ChatGPT to organize and structure
4. Refine through conversation
5. Copy final output
Result: Content drafted while walking/commuting, hands-free

### Workflow: Quick Social Graphics (DALL-E)
1. Describe your visual concept with specific style references
2. "Minimalist illustration of [concept], flat design, [brand colors]"
3. Generate 3-4 variations
4. Download best one, add text overlay in Canva
5. Post
Result: Custom graphics in 5 minutes without stock photos
