## Solopreneur workflows (concrete step-by-step)

### Workflow: Podcast Editing Made Simple
1. Record audio directly in Descript or import file
2. AI transcribes automatically
3. Delete filler words with one-click removal
4. Cut sections by highlighting and deleting text
5. Export polished audio
Result: Podcast editing in minutes, not hours

### Workflow: Video Content to Social Clips
1. Import long-form video (YouTube video, webinar)
2. AI generates transcript
3. Use AI Clips feature to find highlight moments
4. Edit each clip's transcript for tighter cut
5. Export in vertical format for social
Result: One video → multiple social clips

### Workflow: Screen Recording with Voice Correction
1. Record screen + voice for tutorial
2. If you misspeak, just fix the transcript
3. Use Overdub to regenerate that sentence in your voice
4. Remove ums/ahs automatically
5. Add AI eye contact for webcam footage
Result: Perfect tutorials without re-recording

### Workflow: Repurpose Zoom Calls
1. Import Zoom recording
2. Descript transcribes with speaker labels
3. Find quotable moments using search
4. Export clips for testimonials or content
5. Add captions automatically
Result: Client calls become marketing assets
