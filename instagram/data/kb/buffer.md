## Solopreneur workflows (concrete step-by-step)

### Workflow: Weekly Content Batching
1. Connect your 3 social channels (free)
2. Open Buffer queue view
3. Batch create posts for the week
4. Use AI Assistant for caption help
5. Schedule optimal times
Result: Week of content scheduled in one session

### Workflow: Cross-Platform Posting
1. Create content once
2. Customize for each platform
3. Adjust image sizes/formats
4. Schedule across channels
5. Post goes live everywhere
Result: Consistent presence without repetition

### Workflow: Engagement Time Optimization
1. Post consistently for 2-4 weeks
2. Review analytics for best times
3. Adjust posting schedule
4. Buffer suggests optimal slots
5. Improve engagement over time
Result: Data-driven posting schedule

### Workflow: Team Content Collaboration
1. Set up team workspace (paid)
2. Team members draft content
3. Approval workflows before posting
4. Track what's scheduled
5. Coordinate without confusion
Result: Team posting without overlap

### Buffer vs alternatives:
- Buffer: Simplest, cleanest interface
- Later: Better for Instagram-first
- Hootsuite: More features, more complex
- Free tier: Buffer (3 channels) vs Later (1 user)
