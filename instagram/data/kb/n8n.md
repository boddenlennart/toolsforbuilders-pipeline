## Solopreneur workflows (concrete step-by-step)

### Workflow: Instagram Content Pipeline
1. Google Sheets trigger: new row added to content calendar
2. AI node: Claude generates caption from topic column
3. Image generation: connect to Gemini or DALL-E API
4. Webhook: send to Later/Buffer for scheduling
5. Update sheet with "scheduled" status
Result: Content idea → scheduled post without touching each tool

### Workflow: Lead Notification System
1. Email trigger: new email matching criteria arrives
2. AI node: Claude extracts sender info and intent
3. Conditional: if lead detected, create CRM entry
4. Slack/Telegram notification with summary
5. Auto-draft response template
Result: Never miss a lead, instant notification with context

### Workflow: Competitor Monitoring
1. Schedule: daily at 9 AM
2. HTTP node: fetch competitor RSS/social feeds
3. AI node: summarize new content, identify trends
4. Store in Notion/Airtable
5. Weekly digest email with insights
Result: Automated competitive intelligence

### Workflow: AI Agent Loop (Advanced)
1. Trigger: user request via webhook
2. AI agent node: Claude analyzes request
3. Agent decides next action (search, create, respond)
4. Loop: continue until task complete
5. Return result via webhook response
Result: True agentic automation that handles complex requests
